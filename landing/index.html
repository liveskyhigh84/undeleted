How it works

Three commands. No account, no server, no exceptions.

Every step runs locally or in your own free GitHub Actions job. Nothing routes through infrastructure anyone else operates.

Connect your own token

Generate a personal API token from Todoist or Asana's own settings. It's stored in your Keychain, never sent to us, because there's no "us" in the data path.

Automatic snapshots

A scheduled job pulls your task list and commits it to a git repo you control. Git's own history is the diff engine, nothing custom to trust.

Restore what's missing

One command diffs any past snapshot against your live list and recreates exactly what disappeared. Never destructive, never overwrites.

FAQ

Before you ask

Do you ever see my tasks?

No. The tool runs on your machine or your own GitHub Actions job, using a token only you hold. There is no server we operate that your data passes through.

Is this affiliated with Todoist or Asana?

No. UnDeleted is an independent third-party tool built on their public APIs, not created by, affiliated with, or supported by Doist or Asana, Inc.

What if I lose tasks it can't restore?

Restore only recreates tasks that exist in a past snapshot. If something was deleted before your first snapshot ran, there's nothing to restore from: set it up before you need it, not after.

Does it modify or delete anything?

No. Restore is strictly additive, it only recreates what's missing. It never overwrites or deletes existing tasks.
