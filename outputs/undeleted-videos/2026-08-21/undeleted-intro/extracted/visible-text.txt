[div] How it works
[h2] Three commands. No account, no server, no exceptions.
[p] Every step runs locally or in your own free GitHub Actions job. Nothing routes through infrastructure anyone else operates.
[h3] Connect your own token
[p] Generate a personal API token from Todoist or Asana's own settings. It's stored in your Keychain, never sent to us, because there's no "us" in the data path.
[h3] Automatic snapshots
[p] A scheduled job pulls your task list and commits it to a git repo you control. Git's own history is the diff engine, nothing custom to trust.
[h3] Restore what's missing
[p] One command diffs any past snapshot against your live list and recreates exactly what disappeared. Never destructive, never overwrites.

[div] FAQ
[h2] Before you ask
[h3] Do you ever see my tasks?
[p] No. The tool runs on your machine or your own GitHub Actions job, using a token only you hold. There is no server we operate that your data passes through.
[h3] Is this affiliated with Todoist or Asana?
[p] No. UnDeleted is an independent third-party tool built on their public APIs, not created by, affiliated with, or supported by Doist or Asana, Inc.
[h3] What if I lose tasks it can't restore?
[p] Restore only recreates tasks that exist in a past snapshot. If something was deleted before your first snapshot ran, there's nothing to restore from: set it up before you need it, not after.
[h3] Does it modify or delete anything?
[p] No. Restore is strictly additive, it only recreates what's missing. It never overwrites or deletes existing tasks.
