# Directory submissions — full list (research only, nothing submitted)

LAUNCH.md already names terminal-trove.com, `awesome-cli-apps`, and alternativeto.net.
This adds the rest of the real, currently-active free dev-tool directories worth a submission,
found via the directory-submissions skill's method. All free, all still accepting listings as
of this research pass — verify each is still open before submitting since directory sites
churn.

## High-fit (CLI / dev tool, free-tier friendly)

| Directory | Why it fits | Submit type |
|---|---|---|
| terminal-trove.com | Already in LAUNCH.md — CLI-tool-specific audience | Form submission |
| `awesome-cli-apps` (GitHub) | Already in LAUNCH.md — PR-based, async review | Pull request |
| alternativeto.net | Already in LAUNCH.md — captures "todoist backup" search | Form submission |
| Uneed | New 2026 Product-Hunt-style board, free tier, dev-tool friendly | Form submission |
| Peerlist Launchpad | Dev-community launch board, decent organic reach in the indie-hacker crowd | Form submission |
| Microlaunch | Free launch board, low competition, good for a niche CLI tool | Form submission |
| Fazier | Free-tier launch board, active in 2026 | Form submission |
| Dev Hunt | Developer-tool-specific Product Hunt alternative — strong fit given UnDeleted's audience is developers | Form submission |
| Tiny Startups | Community for small/bootstrapped tools, good fit for a $29 one-time indie product | Form submission |
| Smol Launch | Free, low-friction, indie-hacker audience | Form submission |
| Launching Next | Free launch calendar/board | Form submission |
| SaaSHub | Lists non-SaaS dev tools too; "alternative to" pages compound over time like alternativeto.net | Form submission |
| StackShare | Lets you list the tool as part of a stack — secondary discovery, not primary launch | Profile/tool listing |

## Medium-fit (broader, still relevant)

| Directory | Why it fits | Submit type |
|---|---|---|
| Console.dev (newsletter + directory) | Curated dev-tool newsletter — harder to get in, high-trust audience if accepted | Submission form |
| BetaList | Pre-launch/early-stage audience, less CLI-specific but decent reach | Form submission |
| Indie Hackers "Products" | Community already primed for a $29 one-time indie tool story | Product listing |

## Skip / low-fit

- G2 / Capterra — built for team-buying-decision SaaS categories, wrong shape for a $29 personal CLI tool. Not worth the listing effort.
- App-store-style directories (mobile) — not applicable, UnDeleted is a CLI.
